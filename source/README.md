# Ivalice Together

Local co-op for up to three players in FINAL FANTASY XII THE ZODIAC AGE.

## Install

1. Install [FF12 External File Loader 1.5.2](https://www.nexusmods.com/finalfantasy12/mods/170), the **module** version of [FF12 tkMalloc Fix 0.2.1](https://www.nexusmods.com/finalfantasy12/mods/475?tab=files), and [Microsoft Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe). The FF12 LUA Loader is not required by Ivalice Together.
2. Install this ZIP with the FFXII MO2 plugin, Vortex, or extract it into the game's main folder.
3. Open `x64/IvaliceTogetherConfig.exe`, configure the party and controllers, then close it.
4. Start the game through Steam. Co-op loads automatically.

With MO2, enable this ZIP and the two required loader mods, run the configurator through MO2 once, then start **FFXII (Modded)**. Manual and mod-manager installations use the same ZIP and the same files.

If you use Vortex, start the game through Steam after deployment. Starting FFXII from Vortex may crash on some systems.

Supports the Steam 1.0.4.0 x64 game build on Windows 10 or 11. XInput and SDL GameController devices are supported, including DualSense over USB or Bluetooth and DS4Windows virtual controllers. Steam Input works when it exposes the pad as XInput or SDL.
