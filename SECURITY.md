# Security policy

## Reporting a vulnerability

Do not publish exploitable security issues in a public bug report. Contact the
project maintainer privately with reproduction steps, affected versions, and a
minimal proof of concept. A public advisory can be prepared after the issue is
understood and a fix is available.

## Scope

Ivalice Together injects native code into the local game process and starts a
bundled runtime. Releases should be downloaded only from the project's official
GitHub Releases page. Release notes should publish a SHA-256 checksum so users
can verify the archive before installation.

Third-party loaders are separate projects and are not covered by this policy.
